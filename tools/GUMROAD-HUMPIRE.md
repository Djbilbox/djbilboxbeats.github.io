## ⚠️ À lire avant de publier

1. **Aucun prix n'est fixé ici.** Il faut d'abord le devis atelier. Marge conseillée : prix de vente ≈ 2,5 à 3 × le coût de production (qui doit inclure la fabrication *et* le port).
2. **Ce sont des pré-commandes.** Gumroad n'a pas de vrai mode pré-commande pour le physique : il faut l'écrire noir sur blanc dans le titre *et* dans la description (« PRÉ-COMMANDE — expédition sous X semaines »), sinon les acheteurs réclament un remboursement.
3. **Activer « Physical product »** sur chaque fiche (sinon Gumroad envoie un fichier au lieu d'une commande) et **renseigner les frais de port** par zone.
4. **Variantes** : créer une variante « Taille » (XS→XXL) pour les textiles, et une variante « Finition » (Argenté / Doré) sur les sacoches.
5. Les maquettes affichées sont des **rendus**, pas des photos. Le préciser dans la description — c'est ce qui évite les litiges.

## Signature 04 — PAYS (à ouvrir au drop 02)

Ne pas créer de fiches tant que le drop 01 n'est pas livré. Le principe :
chaque pièce ci-dessus se décline aux couleurs d'un pays (bombe repeinte
aux 3 couleurs, ou médaillon cerclé du drapeau). Pays prévus : France,
Maroc, Algérie, Tunisie, Sénégal, Côte d'Ivoire, Mali, Cameroun, Congo,
Comores, Portugal, Italie, Espagne, Turquie.

Sonder le Discord avant de produire : ne lancer que les 3 ou 4 pays les
plus demandés.
